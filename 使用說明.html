Windows 可攜測試版

Codex 多模型切換器

在同一個 Windows 視窗管理 Codex 的 OpenAI 與已驗證第三方模型設定，不需要建立一堆桌面捷徑。

目前支援範圍

  • OpenAI：沿用 Codex 原本的 ChatGPT／OpenAI 登入，不保存帳號密碼。
  • DeepSeek：V4 Flash、V4 Pro，使用官方 Responses API。
  • MiniMax M3：尚未完成 Codex Responses API 相容驗證，因此暫停選取。
這是測試版，不是完整正式版。 Gemini、Kimi、ZAI／GLM 國際版與 MiniMax 尚未開放切換；未驗證的模型不會為了湊數而啟用。

第一次使用

  1. 將 ZIP 解壓縮到一般資料夾，不要直接在 ZIP 裡執行。
  2. 確認資料夾內只有 CodexModelSwitcher.exe、providers.json、使用說明.html。
  3. 雙擊 CodexModelSwitcher.exe。不需要系統管理員權限。
  4. 如果 Windows 顯示來源不明或安全警告，請先停止執行，向分享者核對 ZIP 來源與檔案雜湊；不要關閉 Windows 安全功能。
可攜版不代表金鑰放在資料夾裡。 DeepSeek API Key 只會存進目前 Windows 帳號的「認證管理員」，分享 ZIP 不會連同金鑰一起分享。

設定 DeepSeek API Key

  1. 在「供應商」選擇 DeepSeek。
  2. 點「設定 API Key」，貼上自己的金鑰後選擇安全保存。
  3. 程式不會再次顯示已保存金鑰的完整內容。
  4. 需要更換或刪除時，點「管理 API Key」。

金鑰申請與帳戶管理請使用 DeepSeek 官方平台。

測試連線與費用

  1. 選擇 DeepSeek 與模型，並先保存 API Key。
  2. 點「測試連線」。程式會先顯示費用提醒，只有選擇「是」才會連線。
  3. 測試只送固定文字，不讀取專案內容；最多要求 16 個輸出 token，而且不自動重試。
  4. 測試仍可能依供應商價格產生極少量費用。結果若含 token 用量，程式會顯示數字。

價格可能變動，請以 DeepSeek 官方計費頁為準。

安全切換模型

  1. 先在 Codex 保存正在進行的工作，然後由自己關閉 Codex。
  2. 回到切換器選擇供應商與模型。
  3. 點「安全切換設定」，確認畫面上的目標模型。
  4. 程式會先保存首次原始設定與近期備份，驗證暫存設定後才取代正式設定。
  5. 完成後重新開啟 Codex。

切換器只管理模型、供應商與命令式驗證欄位，不應修改插件、MCP Server、權限、通知與專案信任設定。

恢復原始設定

  1. 保存工作並自行關閉 Codex。
  2. 點「恢復原始設定」，核對首次備份時間。
  3. 確認後，程式會先備份目前設定，再恢復第一次切換前的原始檔。
  4. 重新開啟 Codex，確認原有模型、插件與 MCP Server。

恢復設定不會刪除 Windows 認證管理員裡的 API Key；金鑰必須透過「管理 API Key」另外刪除。

資料會送到哪裡

  • 切換器本身不讀取、不保存、不上傳 Codex 專案內容，也沒有遙測或遠端日誌。
  • 按「測試連線」只會把固定測試文字送到所選供應商。
  • 切換後使用 Codex 工作時，Codex 為完成任務所需的提示與專案片段，會傳送給目前選擇的模型供應商。
  • 不要將學生個資、客戶機密或未經授權資料傳給第三方模型。

常見錯誤

畫面訊息代表意思建議處理
API Key 驗證失敗金鑰錯誤或已失效重新設定金鑰，不要把金鑰傳給他人。
API 餘額不足供應商帳戶沒有可用額度到官方平台確認，或切回 OpenAI。
模型或參數無法使用模型可能更名、停用或介面改變停止切換並等待更新供應商目錄。
目前受到限流同時請求過多稍後再試；程式不會自動重送。
請先關閉 Codex為避免設定衝突而停止保存工作後自行關閉 Codex，再重試。

分享前檢查

  • 只分享原始 ZIP，不要加入自己的設定檔或畫面截圖。
  • ZIP 不應包含 .env、憑證、bin、obj、Git 資料或測試檔。
  • 接收者必須使用自己的 API Key；分享者的 Windows 認證不會包含在 ZIP。
