## 一、先看懂幾個名詞

看到這些字不用緊張，意思其實很單純：

| 名詞 | 白話解釋 |
| --- | --- |
| **Codex** | OpenAI 出的 AI 寫程式助理應用程式。這個工具是幫它換模型用的，不是取代它。 |
| **供應商（Provider）** | 提供 AI 模型的公司，例如 OpenAI、DeepSeek、MiniMax。 |
| **模型（Model）** | 供應商提供的某一個 AI 大腦，例如 DeepSeek V4 Flash。同一家公司會有好幾個模型。 |
| **API Key（金鑰）** | 一串很長的英數字密碼，用來證明「這些用量算在我的帳上」。**等同你的信用卡，絕對不能給別人。** |
| **`config.toml`** | Codex 存設定的檔案。以前要手動改它才能換模型，這個工具就是幫你安全地改它。 |
| **Windows 認證管理員** | Windows 內建的密碼保險箱。你的 API Key 會存在這裡，不會存在本程式的資料夾裡。 |

## 二、開始之前的三個確認

**確認 1：你的電腦符合條件**

- Windows 10 或 Windows 11，而且是 64 位元（現在的電腦幾乎都是）。
- **不需要**額外安裝 .NET，**不需要**系統管理員權限。

**確認 2：你已經裝好 Codex，而且至少成功打開過一次**

這一點很重要。本工具需要讀取 Codex 的設定檔，而那個檔案是 Codex **第一次啟動時才會建立**的。
如果你還沒裝 Codex，請先去安裝並打開一次，再回來看這份教學。

**確認 3：你知道要自己付錢**

- 本工具**不含任何 API Key**，也**不幫你付費**。
- DeepSeek、MiniMax 的費用由你自己的帳戶支出，用多少算多少。
- 好消息是這類模型通常比較便宜，測試連線一次大約只花掉不到一毛錢。

## 步驟 1：下載並解壓縮

1. 到本專案的 **[Releases](../../releases)** 頁面。
2. 下載最新的 `Codex-Model-Switcher-Windows-x64-v*.zip`。
3. 在下載的 ZIP 上按右鍵 →「解壓縮全部」。
4. **把解壓縮出來的資料夾放到一個固定、以後不會亂搬的位置**，建議 `C:\Tools\Codex-Model-Switcher`。

> ### ⚠️ 為什麼位置不能亂搬？
> 切換模型時，程式會把**自己的所在路徑**寫進 Codex 的設定裡，之後 Codex 需要靠這個路徑回來跟切換器要金鑰。
> 如果你之後把資料夾搬走或刪掉，Codex 會找不到金鑰而無法運作。
> **要搬移或刪除之前，請先在程式裡按「恢復原始設定」**，搬完再重新切換一次就好。

解壓縮後資料夾裡應該剛好只有這 4 個檔案：

```
Codex-Model-Switcher/
├─ CodexModelSwitcher.exe   ← 主程式，雙擊這個
├─ providers.json           ← 供應商清單（裡面沒有金鑰）
├─ 使用說明.html            ← 離線版說明書
└─ LICENSE.txt              ← 授權條款
```

如果多出奇怪的檔案，**請不要執行**，回到 Releases 頁面重新下載。

## 步驟 2：第一次打開程式

雙擊 `CodexModelSwitcher.exe`。

### 如果 Windows 跳出藍色警告視窗

畫面會顯示「Windows 已保護您的電腦」之類的訊息。**這是正常的**，因為本程式**還沒有購買程式碼簽章憑證**（那要另外花錢），所以 Windows 不認得發行者。

如果你確定是從本專案的 Releases 頁面下載的，可以這樣做：

1. 點警告視窗上的「**其他資訊**」。
2. 點下方出現的「**仍要執行**」。

> **請務必核對來源。** 如果這個 ZIP 是別人私下傳給你的、不是你自己從官方 Releases 頁面下載的，**請直接停止**，不要按「仍要執行」，也不要為了執行它而關掉防毒軟體。
> 想更謹慎的話，可以比對 Release 頁面公布的 SHA256 檔案雜湊值。

### 程式打開後你會看到

- 上方：**目前 Codex 使用的供應商與模型**
- 中間：**供應商**、**模型**兩個下拉選單，以及金鑰狀態
- 下方按鈕：`設定 API Key`、`測試連線`、`恢復原始設定`、`安全切換設定`

如果上方顯示「尚未找到 Codex 設定」，代表 Codex 還沒被啟動過 → 請回去打開一次 Codex，再重開本工具。

## 步驟 3：申請 API Key

**只有要用 DeepSeek 或 MiniMax 時才需要這一步。**
如果你只是要切回 OpenAI，請直接跳到 [步驟 6](#步驟-6正式切換模型)——OpenAI 沿用 Codex 原本的登入，不需要金鑰。

### 3-A：申請 DeepSeek 金鑰

1. 打開 <https://platform.deepseek.com/api_keys>。
2. 註冊或登入帳號。
3. 進入帳戶的**儲值／餘額**頁面，先加值一小筆金額（沒有餘額的話，之後測試連線會顯示「API 餘額不足」）。
4. 回到 API Keys 頁面，點「建立 API Key」之類的按鈕。
5. **金鑰只會完整顯示這一次**，請立刻按複製，先貼在記事本暫存。

### 3-B：申請 MiniMax 金鑰

1. 打開 <https://platform.minimax.io>。
2. 註冊或登入（請確認用的是**國際版**平台）。
3. 一樣先確認帳戶有餘額。
4. 在帳戶或開發者設定裡找到 API Key 頁面，建立一組新的金鑰並複製。

> 以上網站的畫面配置可能隨時改版，但流程都是：**登入 → 確認餘額 → 建立 API Key → 複製**。

> ### 🔒 金鑰安全三原則
> 1. **不要**貼到聊天群組、社群貼文、截圖裡。
> 2. **不要**存進會同步到雲端或分享出去的檔案。
> 3. 一旦懷疑外流，馬上到官方平台**刪除該金鑰並重新建立**一組。

## 步驟 4：把 API Key 存進切換器

1. 在「供應商」下拉選單選擇 **DeepSeek** 或 **MiniMax**。
2. 點 **`設定 API Key`**。
3. 把剛剛複製的金鑰貼進去。
4. 點 **`安全保存`**。

完成後，金鑰狀態會變成「**已安全保存**」。

存好之後：

- 金鑰會存進 **Windows 認證管理員**，**不會**寫進程式資料夾、**不會**寫進 Codex 的 `config.toml`。
- 程式**不會**再次顯示完整金鑰內容（這是刻意的安全設計）。
- 要更換或刪除，同一顆按鈕會變成 **`管理 API Key`**。

> 存好之後，可以把記事本裡暫存的那份金鑰刪掉了。

## 步驟 5：測試連線

正式切換之前，先確認金鑰真的能用。

1. 選好供應商與模型（例如 DeepSeek + DeepSeek V4 Flash）。
2. 點 **`測試連線`**。
3. 程式會先跳出**費用提醒**，選「是」才會真的連線。
4. 等幾秒鐘看結果。

這個測試很省：只送一段固定的測試文字，**不會讀取你的任何專案內容**，最多只要求 16 個輸出 token，失敗也不會自動重試。花費通常低於新台幣一毛錢。

**看到成功訊息** → 太好了，繼續下一步。
**看到錯誤訊息** → 請對照本文最後的[錯誤訊息對照表](#錯誤訊息對照表)。

## 步驟 6：正式切換模型

> ### ⚠️ 一定要先關掉 Codex
> 如果 Codex 還開著，程式會擋下來並提醒你。**它不會強制關掉 Codex**，以免你的工作沒存到。

1. 回到 Codex，**存好正在進行的工作，然後自己關掉 Codex**。
2. 回到切換器，選好要用的供應商與模型。
3. 點 **`安全切換設定`**。
4. **第一次**切換到第三方供應商時，會跳出一次「資料流提醒」——請讀完再按「是」（詳見[關於安全與隱私](#關於安全與隱私)）。
5. 確認畫面會顯示即將切換的供應商與模型，確定無誤按「是」。
6. 看到「切換完成」訊息後，**自己重新打開 Codex**。

程式在背後做了這些保護，你不用手動處理：

- 切換前**自動備份**（第一次會另外保留一份「原始設定」永久備份，另外保留最近 5 次的備份）
- 先寫到暫存檔並**驗證通過後**，才取代正式設定
- 只修改**模型相關**的欄位，**不會動到**你的插件、MCP Server、權限、通知與專案信任設定
- 萬一失敗，會保留或還原原本的設定

## 步驟 7：確認真的切換成功

打開 Codex 後，你**很可能會發現模型選單顯示「自訂 / Custom」**。

> ### ✅ 這是正常的，不是壞掉
> 桌面版 Codex 的原生選單不會列出第三方模型的名字，所以顯示成「自訂」。

要確定它真的在用新模型，用這兩個方法驗證：

1. **隨便問一句話**，看它有沒有正常回應。有回應就代表請求已經由你選的供應商處理了。
2. **去供應商的官方用量頁面看 token 數字**有沒有增加。這是最確定的證據。

## 步驟 8：換回原本的設定

隨時想切回去（或工具用不順手想移除）都可以：

1. 在 Codex 存好工作，**自己關掉 Codex**。
2. 回到切換器，點 **`恢復原始設定`**。
3. 核對畫面上顯示的「首次備份時間」，確認後按確定。
4. 程式會先備份目前設定，再還原成**你第一次使用本工具之前**的原始設定。
5. 重新打開 Codex，確認原有的模型、插件與 MCP Server 都還在。

> **恢復設定不會刪掉你存的 API Key。** 金鑰要另外從 `管理 API Key` 裡刪除，或到 Windows 認證管理員刪除（見[完全移除本工具](#完全移除本工具)）。

## 進階：新增自訂供應商

> 這一段是給比較進階的使用者。**新手可以完全跳過**。

如果某家供應商**明確標示支援 OpenAI Responses API**，可以自己加進來：

1. 點 `新增自訂供應商…`。
2. 填寫：顯示名稱、Base URL（要 `https://` 開頭的完整網址）、模型 ID、API Key、上下文長度、是否支援圖片、可用推理等級。
3. 點 `驗證並加入`。程式會依序送出**一次最小文字測試**與**一次工具呼叫測試**，**兩項都通過**才會保存。
4. 任何一項失敗，供應商與金鑰**都不會被保存**。
5. 驗證會產生極少量 API 費用，執行前程式會再次提醒。

自訂清單存在 `C:\Users\你的帳號\.codex\model-switcher\custom-providers.json`，裡面**只有網址與模型資訊，沒有金鑰**。

不需要時，選到該供應商後點 `移除自訂供應商`，可以選擇要不要一併刪除已保存的金鑰。

## 常見問題

**Q：這是 OpenAI 官方出的工具嗎？**
不是。這是個人開發的非官方工具，與 OpenAI、DeepSeek、MiniMax 都沒有隸屬關係。

**Q：這個工具會偷看我的程式碼嗎？**
不會。切換器本身不讀取、不保存、不上傳你的專案內容，也沒有任何遙測或遠端記錄。但請注意：**切換之後你用 Codex 工作時，Codex 為了完成任務會把提示與專案片段送給你選的供應商**——這是使用任何 AI 模型都會有的行為，跟本工具無關。

**Q：我的 API Key 會不會跟著程式被分享出去？**
不會。金鑰存在**你這台電腦、你這個 Windows 帳號**的認證管理員裡，不在程式資料夾內，也不會被打包進 ZIP。你把 ZIP 轉傳給別人，對方必須用自己的金鑰。

**Q：一定要付錢嗎？有免費的嗎？**
切換到 DeepSeek 或 MiniMax 需要你自己的帳戶餘額。切回 OpenAI 則沿用你原本的 Codex 登入，不需要額外金鑰。

**Q：找不到 Codex 設定，怎麼辦？**
代表 Codex 沒被啟動過。請先完整打開一次 Codex，讓它建立設定檔，再重開本工具。

**Q：可以在 Mac 或 Linux 用嗎？**
目前不行，這一版只支援 Windows。

**Q：需要系統管理員權限嗎？**
不需要。

**Q：會自動更新嗎？**
不會。要更新請自己到 Releases 頁面下載新版。

**Q：切換之後 Codex 打不開／怪怪的？**
按 `恢復原始設定` 還原成第一次使用前的設定，就會回到原狀。

**Q：我可以同時裝好幾份這個程式嗎？**
不建議。它們會寫進同一份 Codex 設定，容易互相打架。留一份放在固定位置就好。

**Q：不小心把程式資料夾刪掉／搬走了，Codex 現在報錯！**
把資料夾放回原本的路徑就會恢復。如果找不回來，重新下載並解壓縮到**原本那個路徑**，或重新解壓到新位置後再執行一次「安全切換設定」，讓程式把新路徑寫進去。

## 錯誤訊息對照表

| 畫面訊息 | 代表意思 | 建議處理 |
| --- | --- | --- |
| API Key 驗證失敗 | 金鑰打錯、複製不完整或已失效 | 回官方平台重新建立一組，再重新設定。**不要**把金鑰傳給任何人 |
| API 餘額不足 | 供應商帳戶沒有可用額度 | 到官方平台加值，或先切回 OpenAI |
| 找不到 API 端點 | 供應商網址或 API 可能改版了 | 自訂供應商請檢查 Base URL；內建供應商請等待更新 |
| 模型或參數無法使用 | 模型可能改名、停用或介面改變 | 先不要切換，改選其他模型 |
| 目前受到限流 | 短時間送出太多請求 | 等一下再試。程式不會自動重送 |
| 請先關閉 Codex | 為了避免設定衝突而擋下 | 存好工作、自己關掉 Codex，再重試 |
| 連線逾時 | 30 秒內沒收到回應 | 檢查網路，或稍後再試 |
| 無法建立安全連線 | 網路不通或供應商服務中斷 | 檢查網路連線與防火牆 |
| 尚未找到 Codex 設定 | Codex 還沒被啟動過 | 先完整打開一次 Codex |
| 切換失敗，原設定已保留 | 寫入過程出錯，但**你的原設定沒事** | 確認 Codex 已關閉後重試；仍失敗可按 `恢復原始設定` |

> 所有錯誤訊息都經過處理，**不會顯示你的 API Key、完整檔案路徑或 API 回應內容**。

## 完全移除本工具

想乾淨地移除，請照這個順序：

1. **先還原設定**：在 Codex 存好工作並關閉 → 打開切換器 → 按 `恢復原始設定`。
2. **刪除已保存的金鑰**：在切換器裡對每個供應商點 `管理 API Key` → `刪除金鑰`。
   （或到 Windows：控制台 → 使用者帳戶 → **認證管理員** → Windows 認證，刪除開頭為 `CodexModelSwitcher/provider/` 的項目。）
3. **刪除程式資料夾**：直接刪掉整個 `Codex-Model-Switcher` 資料夾。本程式沒有安裝程式，不會留在「新增或移除程式」清單裡。
4. **（選用）清掉殘留設定**：本工具在 `C:\Users\你的帳號\.codex\model-switcher\` 放了備份與自訂清單。確定不再需要備份後，可以刪掉這個資料夾。

## 關於安全與隱私

**本工具會做的事**

- 把 API Key 存進 Windows 認證管理員（不寫進任何設定檔）
- 只修改 Codex 設定中與模型相關的欄位
- 修改前自動備份，驗證通過才寫入
- 錯誤訊息一律遮蔽金鑰、路徑與 API 回應內容

**本工具不會做的事**

- 不蒐集、不上傳你的專案內容、金鑰、使用紀錄或個資
- 沒有遙測、廣告、追蹤或遠端記錄
- 不會覆蓋你的插件、MCP Server、權限、通知與專案信任設定
- 不會強制關閉 Codex

**你自己要注意的事**
